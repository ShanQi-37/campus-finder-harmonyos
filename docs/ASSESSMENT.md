# 课程评分项复核

复核日期为 2026 年 11 月 24 日。核对范围为本地已安装的拾光校园精修版。证据来自源码、92 项回归、HarmonyOS API 26 构建、DevEco Studio 原生 Previewer 和 Pura 90 Pro 模拟器。

| 评分项 | 分值 | 当前实现与可展示证据 |
| --- | ---: | --- |
| 选题与需求 | 10 | 校园失物招领覆盖失主、拾获者和发布者核对，包含发布、发现线索、申请、交接与统计。旧提交清单记有选题登记，正式班级记录、去重和独立开发规则由课程方核定。 |
| UI 布局与容器组件 | 20 | 广场和长表单采用 Scroll，匹配提醒采用 List，发布分类和统计指标采用 Grid。共用 Row、Column 对齐卡片与表单。核对了原生预览里的广场、详情和统计布局，以及模拟器上的桌面图标、广场和个人页。 |
| 自定义组件与状态管理 | 20 | 复用 PageHeader、ItemCard、StatePanel、SegmentTab、BottomNav 和图表。ComponentV2、Local、Param 和 Event 负责表单、筛选和页面刷新。接口状态模型和草稿规则有自动化覆盖。 |
| Navigation 与路由 | 15 | NavPathStack 管理 12 个注册目的地。启事详情传 ID，匹配对比传双方启事 ID，统计明细传日期、类别和状态。实际点开详情与统计明细，模拟器复验从匹配列表返回个人页。 |
| 网络交互 | 15 | NetworkKit 请求本机 HTTP Mock 并把响应渲染到页面。Previewer 已访问正在运行的 Mock。隔离预览覆盖加载、HTTP 503、空列表和恢复。自动化覆盖响应格式异常以及草稿、认领、匹配等业务接口。 |
| Git 版本管理 | 10 | 核对时本地 HEAD 含 48 个提交，分阶段记录 UI、发布、认领、统计和媒体。公开 main 已匿名验证可访问，指向 `ac2fb3b`。现有报告附有较早的真实 Gitk 图。最终提交材料仍需与本地精修版的源码、提交记录和截图对齐。 |
| 代码规范与文档 | 10 | 客户端按页面、组件、状态模型和服务分层。有运行说明、接口文档和演示步骤。已核对本地学校模板和报告的目录结构及 Gitk 附图。现有提交版报告描述较早版本，截图、功能清单和测试数据需在正式提交前更新。 |
| 网络动态数据可视化 | +10 | /api/statistics 驱动寻回率环图、类别柱状图、趋势折线图。隔离 Previewer 新增一条虚构启事后，刷新使有效启事从 12 变为 13，待寻回从 8 变为 9，寻回率从 33% 变为 31%。从指标可进入包含新记录的 13 条统计明细。 |

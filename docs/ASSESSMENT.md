# 课程评分项复核

复核日期为 2026 年 11 月 23 日。项目为原生 HarmonyOS 应用拾光校园。下面的结论以源码、构建、测试和标明环境的运行记录为依据。班级登记及评分由课程方核定。

| 评分项 | 分值 | 当前实现与可展示证据 |
| --- | ---: | --- |
| 选题与需求 | 10 | 面向拾获者、失主和核对发布者，覆盖发布、发现线索、申请、交接与统计。课程选题登记和同班重名情况需对照班级登记表。 |
| UI 布局与容器组件 | 20 | 广场和列表使用 List，发布表单和长内容使用 Scroll，筛选、步骤和数据卡用 Row、Column、Grid 排版。既有记录含手机和折叠屏模拟器，新增交互见本轮原生预览。 |
| 自定义组件与状态管理 | 20 | 复用 PageHeader、ItemCard、StatePanel、SegmentTab、BottomNav 和图表。V2 状态驱动表单、筛选与分页。描述找物区分正在编辑的条件和已提交查询，重试与从详情返回沿用已提交的页码和条件。 |
| Navigation 与路由 | 15 | Index 注册 12 个业务页面。启事详情传 ID，拍照候选携带查找来源，统计明细传日期、类别及状态。分类柱状图的有效柱可直接打开对应启事，返回后仍在类别视图。 |
| 网络交互 | 15 | NetworkKit 请求真实运行的本机 HTTP Mock。启事、草稿、申请和统计均经过网络、响应校验和界面渲染。加载、无结果、数据形状异常及重试均有处理。AI 未配置时可用文字或手动条件找物。 |
| Git 版本管理 | 10 | 公开 main 保留查找、发布、交接、统计修正、媒体、AI 和本轮复核的阶段提交。提交顺序及远端状态可用 Git 日志查看。公开提交只含脱敏源码、文档与虚构数据截图。 |
| 代码规范与文档 | 10 | 客户端页面、状态模型、服务与组件分层，Node 服务保存业务状态，关键日期口径、状态边界和演示步骤有文档。课程论文和开发报告另作本地材料。 |
| 网络动态数据可视化 | +10 | /api/statistics 驱动寻回率环图、类别柱状图、发布与实际寻回折线图。可用 7／14／30 日、类别和日期明细交互。/api/statistics/photo-search 驱动拍照找物阶段柱状图；其确认寻回数来自关联申请的实际通过结果。 |

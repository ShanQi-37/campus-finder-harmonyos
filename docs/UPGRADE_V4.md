# 第四版个人管理升级

2026年10月25日。在既有七页课堂演示业务上，补齐常用管理操作。

## 新增功能

- 我的启事提供全部、待寻回、已寻回、已撤回状态；复用HTTP筛选、分页与返回刷新。已撤回仍仅本人可见。
- 申请中心按方向与处理状态组合查看，默认待核对；暂无任务时可一键查看全部。已通过、未通过、已取消均有明确入口，计数来自当前筛选结果。
- 已保存草稿出现舍弃入口，二次确认说明会清除本页未保存编辑；继续填写保留内容，确认后恢复空白并更新个人草稿数。
- 舍弃请求带requestId和保存时间。服务端先检查当前身份及版本，再原子落盘；旧版本409，失败保留原草稿，重复舍弃不产生副作用。每次草稿保存时间严格递增，防止同毫秒版本重合。

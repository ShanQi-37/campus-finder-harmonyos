# 系统性检查与纠错

检查日期：2026年10月24日。范围为本机课堂演示工程、实际HTTP服务、ArkTS接口与状态模型、原生Previewer和交付材料。

## 已复现并修复

| 问题 | 修复与验证 |
| --- | --- |
| 汉字跨HTTP数据块时被逐块转成乱码 | 按字节限流并合并Buffer后严格解码一次；故意在汉字第一个字节后拆包验证 |
| 发布已成功但响应丢失，重存同草稿后重试仍留草稿 | 新建和幂等重试均原子清理相同身份及requestId草稿；不误删其他草稿，落盘失败回滚 |
| 相同requestId、不同内容也被当成成功 | 初次规范化字段SHA256核对；冲突409；编辑后重试原始内容仍返回原记录，内部指纹不外发 |
| 午夜或未来记录导致统计总量与每日数不一致 | 一次捕获上海日期锚点，首尾双向限制窗口，验证类别及趋势之和等于总量 |
| 合法JSON但嵌套字段错误进入界面 | ResponseGuard校验13类实际Api读写调用，错误格式变为可读错误；finally始终销毁HTTP对象 |
| 个人详情返回重置到第一页 | onShown保留当前页，仍采用服务端收敛页码；原生从第二页打开详情并返回验证 |
| 加载期间任务误显示为零、描述字数可能保留初值 | 明确syncing省略号与直接响应式字数绑定；构建通过，个人任务实际加载显示正确 |
| 写入期间从卡片跳走可能留下busy | 禁用相关跳转并无条件释放busy；旧页面数据仍受active与generation保护 |
| 趋势日期与点不对应，最后日期相邻重叠 | 标签和折线共用坐标；保留末日、去掉紧邻中间标签；14/30日原生复验清晰 |

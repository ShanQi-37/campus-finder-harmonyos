# 答辩演示路线

先按 [运行说明](../README.md) 启动本机 HTTP Mock 和 DevEco 预览或模拟器。使用虚构身份与示例物品；页面数量随当前记录变化。完整模型、接口和界面验证记录见 [验证记录](VALIDATION.md)。

## 启事与认领闭环

1. 在广场输入关键词，切换类型或类别并翻页。打开一条待寻回启事，确认详情中的地点、日期与状态。选择「收藏」后，可在「我的校园」查看该条记录。
2. 到发布页填入虚构示例，保存草稿后离开。从「我的校园」恢复，走完基本信息、补充线索、预览。发布后核对草稿和本人启事数量。需要复测撤回时使用本人新发布的虚构启事。
3. 用「校园同学」登录并提交认领申请。到「我的 → 退出登录」，用「互助同学」登录，从待核对进入申请中心。确认寻回后重新登录申请人账号即可查看结果。演示账号可在登录页展开查看，密码为 `campus123`。已处理的示例请换用其他开放招领记录。
4. 从相似线索进入候选对比，核对类别、地点、日期和描述，再打开候选详情。返回后可继续看原来的列表。

## 图表与数据刷新

1. 先记下统计页的日期、类别、有效启事数和已寻回数。切换寻回率环图、类别柱状图、发布趋势和寻回趋势。
2. 点击类别柱状图上的一条有效类别，核对明细页使用该类别及当前发布日期范围，条数与柱子一致。返回后仍在类别分布。
3. 选择趋势上的日期，打开单日明细。发布趋势以发布日期为准，寻回趋势以可靠确认日期为准。旧记录缺少可靠确认日期的数量在寻回趋势内单独提示。
4. 完成一条虚构启事的发布或认领确认后，刷新相同日期和类别。核对总览及明细。若启事发布早于当前窗口、交接发生在窗内，应到确认寻回趋势查看。
5. 可用模型时，从拍照找物的候选进入详情、提交并通过申请，再去「拍照找物统计」。切换 7／14／30 日，核对识别、候选、申请和确认数量。统计从同一次查找识别到人工交接；普通认领不会计入拍照来源。

## AI 与容错

描述找物可先填入虚构描述，再提取关键词、地点、类别和发生日期，核对后执行搜索。服务未配置时，可使用物品关键词、发生地点或类别手动查。翻页遇到网络失败时，恢复 Mock 后点重试，沿用当时的筛选和页码。

照片和短视频的演示需要可用的系统相机能力。准备没有人脸、号码或联系方式的样图。配置模型后测试分类、标题和外观描述建议，以及上传失败后手填。认领结果仍按双方核对处理。

可在隔离 Mock 中用 /__test/mode 切换 error、empty、slow 或 shape 后刷新观察，再恢复 normal。提交证据可配合 Git 阶段日志、原生截图与运行步骤展示。课程选题登记请以班级记录为准。

# Public repository scope

This repository contains the native ArkTS application, its local HTTP Mock, tests, generic documentation, and screenshots showing fictional demo data only.

The implementation stages were copied from a local course project into a separate repository after privacy filtering. Stage messages and actual original timestamps are retained; commit hashes differ because identifying text was removed from historical versions. The original local implementation history remains available separately. Codex assisted with implementation, and the historical implementation commits retain their original generic author identity.

Subsequent maintainer commits are created by local Git using the repository owner's GitHub account and GitHub-provided noreply address. This associates new commits with the account without publishing a personal email address. Updating the local commit identity does not rewrite historical authorship or change the implementation assistance disclosure.

Personal reports, names, student numbers, class and institution details, machine-specific logs, credentials, original IDE captures, source Git bundles, and persistent demo runtime files are excluded. Published PNG files contain only the application viewport; ancillary metadata is stripped without altering image pixels.

The app supports three fixed fictional demo identities and a loopback Mock server. It does not provide production account authentication. See docs/VALIDATION.md for the actual test coverage and limitations.

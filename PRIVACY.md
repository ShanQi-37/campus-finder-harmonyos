# Public repository scope

This repository contains the native ArkTS application, its local HTTP Mock, tests, generic documentation, and screenshots showing fictional demo data only.

The 13 development stages were copied from a local course project into a separate repository after privacy filtering. Stage messages and actual original timestamps are retained; commit hashes differ because identifying text was removed from every historical version. The original local repository is unchanged. Codex assisted with implementation and is shown as the author of these commits.

Personal reports, names, student numbers, class and institution details, machine-specific logs, credentials, original IDE captures, source Git bundles, and persistent demo runtime files are excluded. Published PNG files contain only the application viewport; ancillary metadata is stripped without altering image pixels.

The app uses a fixed fictional identity and a loopback Mock server. It does not provide production account authentication. See docs/VALIDATION.md for the actual test coverage and limitations.
